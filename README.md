# OSAI — AI-Powered Acoustic Awareness

OSAI is a software-first project exploring AI-powered acoustic awareness
and directional visual alerts for drivers.

## Current development scope

- AI-based sound classification
- Direction estimation when supported by the microphone hardware
- Clear visual alerts and event history
- Simulated input for development before hardware integration

## Status

Early development. Hardware integration and model performance
will be validated as the project progresses.
